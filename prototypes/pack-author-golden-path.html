What should first-time Activity Pack authoring feel like?

This prototype asks which authoring entrance is understandable and proportionate while still ending in the same deterministic, immutable Activity Pack Revision. Try each flow, force a privacy failure, and revise a pack without rewriting an existing Room.

Fixed constraints: public first success is non-Rust, under 60 minutes, and machine-verifiable. Prompt assistance is a required first-release capability but remains optional for each author. Pack authorship grants no installation or Room authority. Commands, filenames, and TypeScript are hypotheses for reaction—not frozen APIs.

Provisional recommendation to react to

        
One code-first project contract, with prompt assistance as a required first-release way to create it and an optional choice for each author. The assistant asks focused domain questions, emits the same reviewable source and fixtures, states assumptions, and may propose fixes for deterministic diagnostics. Generate identity metadata and most schemas from typed source. Keep a small human-readable manifest for package facts and limits, not duplicated domain rules. The CLI owns check/build/evidence; a Host Operator explicitly approves local installation. Static Rust crates remain the separation bridge, not the public golden path.

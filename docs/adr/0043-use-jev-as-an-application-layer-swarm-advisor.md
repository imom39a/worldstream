# Use JEV as an application-layer Swarm advisor

Agent Swarm may call hosted JEV as its sole direct-model-API exception, through
a built-in advisor that is disabled by default and enabled explicitly per
Swarm. JEV produces versioned, probabilistic Swarm Assessments from minimized
current projections; it is neither an Agent Participant nor part of
WorldStream Core or the deterministic Swarm Pack. This boundary gains fast
semantic monitoring without granting a fallible remote model work ownership,
Room authority, review votes, Directions, tool access or result acceptance.

The local supervisor owns a one-purpose helper and isolates its API key from
roster agents and their tools. Assessments bind the exact Room Head, evaluation
policy, input and questions, requested and resolved model, answers and
uncertainty. Stale or failed calls cannot affect current work, replay never
repeats inference, and API, credit or budget failure degrades only the optional
advisor. Initial behavior is shadow mode; any later automatic consequence is
limited to operational attention or an ordinary review request through an
existing authority.

# Preserve the kernel and application examples

The product experiments have concluded. Preserve WorldStream as a reusable Room
kernel and a systems-design reference, with Activity Packs, clients, and Agent
Swarm explicitly presented as examples. Remove the hosted catalog, Supabase
integration, Vercel/Fly deployment configuration, product research, transient
evidence reports, compiled browser releases, and unfinished release machinery.
Publish a dependency-free static overview on GitHub Pages.

This supersedes earlier product sequencing, hosted deployment, supported-release,
and adoption commitments. It does not change Room authority, canonical formats,
Pack revision identity, or Replay. Retained executors, golden fixtures, and the
embedded compatibility manifest remain because they are executable inputs, not
marketing or release evidence.

Keep the headless Controller and its typed compatibility contracts where the
operator CLI still depends on them. Retire the hardcoded hosted catalog and its
automatic route registration. Removing every historical type or renaming every
wire field would be a separate compatibility-breaking refactor with little
benefit to this cleanup.

The default build targets the kernel and operator tools; application examples
remain explicitly selectable workspace members. The documentation makes no
production, maintenance, provider-qualification, or live-service promise. Removed
experiments remain discoverable through Git history rather than an archive
directory in the current tree.

The compatibility manifest must match the implemented storage migrations. The
cleanup corrects its stale migration inventory and schema fingerprint, and
updates the corresponding trusted mirror digest. Pack identities and database
migration code do not change.

# Issue tracker: Linear

Issues and specifications for this repository live in Linear.

- Team: Imom39a (`IMO`)
- Project: WorldStream
- Use the connected Linear tools for all operations.

## Conventions

- Create one Linear issue per implementation ticket.
- Assign every created issue to the WorldStream project.
- Apply `ready-for-agent` when the issue is independently implementable.
- Represent dependencies with Linear's native `blocked by` relationships.
- Read full issue descriptions, comments, and relations before acting.
- Work only from the dependency frontier: an issue is ready when all blockers are complete.

## When a skill says “publish to the issue tracker”

Create a Linear issue in team Imom39a and project WorldStream.

## When a skill says “fetch the relevant ticket”

Fetch the complete Linear issue, including comments and blocking relations.

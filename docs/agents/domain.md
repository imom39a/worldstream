# Domain Docs

This repository uses a single domain context.

Before exploring or changing the codebase:

1. Read the root `CONTEXT.md`.
2. Read the ADRs under `docs/adr/` that govern the affected area.
3. Use the canonical vocabulary from `CONTEXT.md` in ticket titles, descriptions, tests, and code.
4. Surface any conflict with an accepted ADR rather than silently overriding it.

Do not introduce context-specific glossaries unless the repository explicitly adopts a `CONTEXT-MAP.md`.

Agent Heist × WebMCP

One live Activity Client can serve a person and their tab-bound browser agent without turning WorldStream into a WebMCP runtime. This page exercises that boundary against one representative Heist move.

Question under test: Can three small, Pack-aware tools let a browser agent read its authorized view, wait for relevant change, and submit a current Heist action—while the shared client remains protocol-thin and the same page stays useful to humans?

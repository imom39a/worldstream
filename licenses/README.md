# Licenses and retained notices

WorldStream is licensed under Apache 2.0; see the root `LICENSE`.
`THIRD-PARTY-NOTICES.txt` and its JSON inventory preserve the notices assembled
for the final experimental distribution. They are a conservative superset after
removal of the hosted platform and release tooling. They are not a manifest of
current runtime dependencies. Current source dependencies are pinned in
`Cargo.lock`, `pnpm-lock.yaml`, and `sdk/python/uv.lock`.

Example artwork and fonts keep their adjacent provenance and license files.
Redistributors should review the dependencies included in their own build.

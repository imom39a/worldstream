# Security

WorldStream is a preserved research project. There is no supported production
release, security maintenance schedule, or guaranteed response time.

Report suspected vulnerabilities privately through
[GitHub Security Advisories](https://github.com/imom39a/worldstream/security/advisories/new).
Include the affected commit and a minimal reproduction using synthetic data.
Keep credentials and participant-private observations out of public issues.

The kernel's trust boundaries are described in [the security model](docs/security.md).
Activity examples and external agent Runners require their own execution and
credential controls; a passing conformance test is not a security audit.
